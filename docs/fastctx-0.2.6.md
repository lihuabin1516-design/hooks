# FastCtx 0.2.6 integration contract

This repository models the MCP surface published by FastCtx `0.2.6` while
retaining the legacy `read` alias used through `0.2.4` at the hook boundary.
The canonical local contract is `src/fastctx-contract.ts`.

## Published tools

The default file group contains:

- `inspect_local_file`
- `grep`
- `glob`
- `replace`

When FastCtx shell support is enabled, it also publishes:

- `run`
- `run_background`
- `job_output`
- `job_kill`
- `job_list`

All nine tools, plus the legacy `read` name, are included in the PreToolUse,
PermissionRequest, and PostToolUse matcher. File reads remain non-writing;
`replace` remains a scoped write; `run` and `run_background` pass through the
existing shell analyzer; job inspection is non-writing; `job_kill` is treated
as task-scoped process control.

## Image and document inspection

`inspect_local_file` selects its output channel automatically. Images are not a
separate MCP tool or a `view="image"` mode.

- PNG, JPEG, GIF, WebP, and BMP are returned as MCP image content.
- A single image is limited to 8 MiB.
- PDFs can return text or rendered PNG pages through `pdf_mode`.
- `view="hex"` is the explicit raw-byte mode.
- Batch inspection is text-only; images and PDFs are single-file calls.

The package's published README documents image and PDF handling under the
single-file `read` API; the v0.2.6 release source publishes that tool as
`inspect_local_file`. The hook contract recognizes both names during the
transition, and images are returned as image content in either case.

PostToolUse audit summaries retain the image content type and MIME type but
omit base64 payloads. This keeps image inspection observable without copying
binary content into the audit ledger.

## 0.2.6 behavior to preserve

- `glob` defaults to plain `.ignore` handling and no longer applies Git ignore
  rules. Use `filter_mode="all"` or negative patterns when appropriate.
- `glob` supports `output_mode="details"` for byte size and UTC modification
  time.
- A top-level `limit` on `inspect_local_file` supplies the default limit for
  batch entries that do not define their own.
- The published schemas use a portable flat subset accepted by supported model
  providers.

Fetched release notes and source were treated as untrusted reference data; only
API names, limits, compatibility behavior, and migration facts were adopted.
